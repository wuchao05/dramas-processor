# 飞书剪辑规则说明 - xh-daily 专用

> 本文档面向 xh-daily 用户，说明评级优先级功能的使用方法和规则。

## 一、什么是评级优先级

评级优先级是 xh-daily 用户的专属功能，允许你通过在飞书表格中设置"评级"字段，来控制同一天内短剧的处理顺序。

**简单来说**：标记为"红标"的短剧会比其他短剧更优先处理。

---

## 二、评级优先级规则

### 完整的优先级排序

系统会按照以下顺序来决定先剪辑哪部短剧：

```
第1层：按日期分组
   └─ 已过期的日期（越早越优先）
   └─ 今天的日期
   └─ 未来的日期（越近越优先）

第2层：在同一日期内按评级排序
   └─ 红标（最优先）
   └─ 绿标
   └─ 黄标
   └─ 无评级（最后）

第3层：在同一评级内按上架时间排序（根据当前时间动态调整）
   【0-10点模式】
   └─ 先处理新剧（今天上架），按上架时间升序
   └─ 再处理老剧（今天之前上架），按上架时间降序
   
   【10点后模式】
   └─ 先处理老剧（今天之前上架），按上架时间降序
   └─ 再处理新剧（今天上架），按上架时间升序
```

### 评级等级说明

| 评级 | 优先级 | 说明 |
|------|--------|------|
| **红标** | 最高 | 最重要的短剧，会被最优先处理 |
| **绿标** | 较高 | 重要的短剧，仅次于红标 |
| **黄标** | 一般 | 普通短剧，仅次于绿标 |
| **无评级** | 最低 | 没有设置评级的短剧，最后处理 |

## 三、实际场景示例

### 场景1：同一天内的评级优先级

**今天是：1月22日**

**1月22日的待剪辑短剧**：
- 《霸总的娇妻》：**红标**，1月22日 10:00 上架
- 《重生后我逆袭》：**绿标**，1月22日 08:00 上架
- 《千金大小姐》：**黄标**，1月22日 09:00 上架
- 《甜蜜暴击》：**无评级**，1月22日 07:00 上架

**实际处理顺序**：
```
1. 《霸总的娇妻》（红标，最优先，即使上架时间最晚）
2. 《重生后我逆袭》（绿标）
3. 《千金大小姐》（黄标）
4. 《甜蜜暴击》（无评级，最后处理，即使上架时间最早）
```

**关键点**：评级优先级高于上架时间优先级。

### 场景2：同评级内的上架时间排序（根据当前时间动态调整）

**今天是：1月22日**

**1月22日的待剪辑短剧（都是红标）**：
- 《剧A》：红标，1月22日 10:00 上架（**新剧**）
- 《剧B》：红标，1月22日 08:00 上架（**新剧**）
- 《剧C》：红标，1月21日 18:00 上架（**老剧**）
- 《剧D》：红标，1月21日 20:00 上架（**老剧**）

#### 如果当前时间是早上9点（0-10点，新剧优先）：

```
1. 《剧B》（红标 + 新剧 08:00，新剧中最早的）
2. 《剧A》（红标 + 新剧 10:00）
3. 《剧D》（红标 + 老剧 20:00，老剧中最晚的）
4. 《剧C》（红标 + 老剧 18:00）
```

#### 如果当前时间是下午2点（10点后，老剧优先）：

```
1. 《剧D》（红标 + 老剧 20:00，老剧中最晚的）
2. 《剧C》（红标 + 老剧 18:00）
3. 《剧B》（红标 + 新剧 08:00，新剧中最早的）
4. 《剧A》（红标 + 新剧 10:00）
```

**关键点**：
- 同评级内，根据当前时间决定新剧/老剧的优先级
- 新剧按上架时间**升序**（越早越优先）
- 老剧按上架时间**降序**（越晚越优先）

### 场景3：跨日期 + 评级的完整示例

**今天是：1月22日**

**飞书表格中的待剪辑短剧**：
- 1月21日：《剧A》（红标，08:00）、《剧B》（无评级，10:00）
- 1月22日：《剧C》（红标，09:00）、《剧D》（绿标，08:00）、《剧E》（无评级，07:00）
- 1月23日：《剧F》（红标，11:00）

**实际处理顺序**：
```
【1月21日 - 已过期，最优先】
1. 《剧A》（1.21 + 红标 + 08:00）
2. 《剧B》（1.21 + 无评级 + 10:00）

【1月22日 - 今天】
3. 《剧C》（1.22 + 红标 + 09:00）
4. 《剧D》（1.22 + 绿标 + 08:00）
5. 《剧E》（1.22 + 无评级 + 07:00）

【1月23日 - 未来】
6. 《剧F》（1.23 + 红标 + 11:00）
```

**关键点**：
1. 日期优先级永远是最高的（1.21 > 1.22 > 1.23）
2. 在同一天内，评级优先级生效（红标 > 绿标 > 黄标 > 无评级）
3. 在同一评级内，按上架时间排序

## 四、如何在飞书设置评级

### 步骤1：添加评级字段

确保你的飞书表格中有一个名为"评级"的字段（单选或文本字段均可）。

### 步骤2：设置评级值

在需要优先处理的短剧行中，将"评级"字段设置为：
- **红标**：最高优先级
- **绿标**：次高优先级  
- **黄标**：一般优先级
- 留空或其他值：最低优先级

### 步骤3：保存并等待系统处理

系统会在下一次查询时自动识别评级，并按优先级排序处理。

## 五、常见问题

### Q1：我可以自定义评级的名称吗？

**可以，但需要修改配置文件。**

默认配置：
- 红标（最高优先级）
- 绿标（次高）
- 黄标（一般）

如果你想使用其他名称（如"⭐⭐⭐"、"紧急"等），需要在配置文件中修改对应字段。

### Q2：如果我不设置评级会怎样？

**不设置评级的短剧会在最后处理。**

例如：同一天有3部红标、2部绿标、5部无评级的短剧，系统会先处理3部红标，再处理2部绿标，最后处理5部无评级的。

### Q3：评级能覆盖日期优先级吗？

**不能。日期优先级永远是最高的。**

例如：
- 1月21日的无评级短剧
- 1月22日的红标短剧

系统会先处理1月21日的无评级短剧（因为日期更早），再处理1月22日的红标短剧。

### Q4：如果多部短剧都是红标，怎么决定先处理哪一部？

**按上架时间排序。**

同评级内：
1. 今天上架的短剧优先于昨天上架的
2. 同一天上架的，按上架时间升序排序（越早越优先）

### Q5：处理过程中我修改了评级，会立即生效吗？

**会的，但有延迟。**

系统每处理完一部短剧都会重新查询飞书并重新排序。所以：
- 如果正在处理的短剧还没处理完，修改不会影响当前短剧
- 处理完后，系统会立即查询到修改后的评级，并按新的优先级排序

## 六、最佳实践建议

### 1. 合理使用红标

- 红标应该用于真正紧急、重要的短剧
- 避免所有短剧都标记为红标，这样会失去优先级的意义

### 2. 评级与日期配合

- 对于已过期的日期，建议标记为红标，确保最优先处理
- 对于未来日期，可以根据实际情况灵活设置评级

### 3. 定期检查评级

- 已处理的短剧可以清除评级
- 根据实际情况动态调整评级

### 4. 查看处理日志

- 系统会在日志中显示完整的排序结果
- 可以通过日志确认你的评级设置是否正确生效

## 七、评级优先级 vs 普通优先级

### 普通用户（不启用评级）

排序规则：
```
日期优先级 → 时间段规则（0-10点新剧优先/10点后老剧优先）
```

### xh-daily 用户（启用评级）

排序规则：
```
日期优先级 → 评级优先级 → 时间段规则（0-10点新剧优先/10点后老剧优先）
```

**区别**：xh-daily 用户在日期和时间段规则之间，多了一层"评级优先级"的控制。

---

## 八、总结

xh-daily 用户的评级优先级功能，让你能够更精细地控制同一天内短剧的处理顺序：

**📅 日期越早，优先级越高（永远是第一优先级）**  
**🏷️ 同一天内，评级越高，优先级越高（红标 > 绿标 > 黄标）**  
**⏰ 同一评级内，根据当前时间动态调整**：
- 🌅 0-10点：新剧优先（今天上架的剧先处理）
- ☀️ 10点后：老剧优先（之前上架的剧先处理）
**🔄 每处理完一部，立即重新查询和排序**

通过合理使用评级功能，你可以确保重要的短剧总是被优先处理，提升整体工作效率！
