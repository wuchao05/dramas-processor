# 飞书剪辑规则说明 - xh-daily 专用

> 本文档面向 xh-daily 用户，说明评级优先级功能的使用方法和规则。

## 一、什么是评级优先级

评级优先级是 xh-daily 用户的专属功能，允许你通过在飞书表格中设置"评级"字段，来控制同一天内短剧的处理顺序。

**简单来说**：标记为"红标"的短剧会比其他短剧更优先处理。

---

## 二、前提条件：源视频目录要求

### 重要提示

**系统只会处理本地存在源视频的短剧！**

在飞书表格中标记"待剪辑"之前，请确保：

### 2.1 源视频目录结构

系统会在配置的源视频目录（默认：`D:\短剧剪辑\源素材视频`）中查找短剧。

**目录结构要求**：
```
D:\短剧剪辑\源素材视频\
├── 霸总的娇妻\
│   ├── 第1集.mp4
│   ├── 第2集.mp4
│   └── ...
├── 重生后我逆袭\
│   ├── 第1集.mp4
│   ├── 第2集.mp4
│   └── ...
└── 千金大小姐\
    ├── 第1集.mp4
    ├── 第2集.mp4
    └── ...
```

### 2.2 剧名必须完全匹配

**关键规则**：飞书表格中的剧名必须与文件夹名称**完全一致**（包括大小写、空格、标点符号）。

**正确示例**：
- 飞书剧名：`霸总的娇妻` → 文件夹：`霸总的娇妻` ✅
- 飞书剧名：`重生后我逆袭` → 文件夹：`重生后我逆袭` ✅

**错误示例**：
- 飞书剧名：`霸总的娇妻` → 文件夹：`霸总的娇妻(完结)` ❌
- 飞书剧名：`重生后我逆袭` → 文件夹：`重生后我逆袭 ` ❌（多了空格）
- 飞书剧名：`千金大小姐` → 文件夹：`千金小姐` ❌（剧名不同）

### 2.3 源视频文件要求

- 支持的视频格式：`.mp4`、`.mkv`、`.avi`、`.mov` 等常见格式
- 文件命名可以是：`第1集.mp4`、`1.mp4`、`ep01.mp4` 等
- 至少需要有足够的集数来生成所需数量的素材

### 2.4 系统处理逻辑

当系统选择处理某部短剧时：

**情况1：找不到文件夹**
```
系统查找：D:\短剧剪辑\源素材视频\霸总的娇妻
结果：文件夹不存在
操作：飞书状态更新为"无源视频"，跳过该剧
```

**情况2：文件夹存在但视频不足**
```
系统查找：D:\短剧剪辑\源素材视频\霸总的娇妻
结果：文件夹存在，但只有3集视频（需要至少8集）
操作：飞书状态更新为"剪辑失败"，备注"请检查源素材目录中是否存在足额的源视频"
```

**情况3：正常处理**
```
系统查找：D:\短剧剪辑\源素材视频\霸总的娇妻
结果：文件夹存在，有充足的视频文件
操作：开始剪辑，飞书状态更新为"剪辑中" → "已剪辑"
```

## 三、评级优先级规则

### 完整的优先级排序

系统会按照以下顺序来决定先剪辑哪部短剧：

```
第1层：按日期分组
   └─ 已过期的日期（越早越优先）
   └─ 今天的日期
   └─ 未来的日期（越近越优先）

第2层：在同一日期内按评级排序
   └─ 红标（最优先）
   └─ 绿标
   └─ 黄标
   └─ 无评级（最后）

第3层：在同一评级内按上架时间排序
   └─ 今天上架的短剧优先
   └─ 在各自组内按上架时间升序排序（越早越优先）
```

### 评级等级说明

| 评级 | 优先级 | 说明 |
|------|--------|------|
| **红标** | 最高 | 最重要的短剧，会被最优先处理 |
| **绿标** | 较高 | 重要的短剧，仅次于红标 |
| **黄标** | 一般 | 普通短剧，仅次于绿标 |
| **无评级** | 最低 | 没有设置评级的短剧，最后处理 |

## 四、实际场景示例

### 场景1：同一天内的评级优先级

**今天是：1月22日**

**1月22日的待剪辑短剧**：
- 《霸总的娇妻》：**红标**，1月22日 10:00 上架
- 《重生后我逆袭》：**绿标**，1月22日 08:00 上架
- 《千金大小姐》：**黄标**，1月22日 09:00 上架
- 《甜蜜暴击》：**无评级**，1月22日 07:00 上架

**实际处理顺序**：
```
1. 《霸总的娇妻》（红标，最优先，即使上架时间最晚）
2. 《重生后我逆袭》（绿标）
3. 《千金大小姐》（黄标）
4. 《甜蜜暴击》（无评级，最后处理，即使上架时间最早）
```

**关键点**：评级优先级高于上架时间优先级。

### 场景2：同评级内的上架时间排序

**今天是：1月22日**

**1月22日的待剪辑短剧（都是红标）**：
- 《剧A》：红标，1月22日 10:00 上架（今天上架）
- 《剧B》：红标，1月22日 08:00 上架（今天上架）
- 《剧C》：红标，1月21日 18:00 上架（昨天上架）
- 《剧D》：红标，1月21日 20:00 上架（昨天上架）

**实际处理顺序**：
```
1. 《剧B》（红标 + 今天上架 08:00，今天上架中最早的）
2. 《剧A》（红标 + 今天上架 10:00）
3. 《剧C》（红标 + 昨天上架 18:00，昨天上架中最早的）
4. 《剧D》（红标 + 昨天上架 20:00）
```

**关键点**：同评级内，今天上架的优先于昨天上架的，同一天上架的按时间先后排序。

### 场景3：跨日期 + 评级的完整示例

**今天是：1月22日**

**飞书表格中的待剪辑短剧**：
- 1月21日：《剧A》（红标，08:00）、《剧B》（无评级，10:00）
- 1月22日：《剧C》（红标，09:00）、《剧D》（绿标，08:00）、《剧E》（无评级，07:00）
- 1月23日：《剧F》（红标，11:00）

**实际处理顺序**：
```
【1月21日 - 已过期，最优先】
1. 《剧A》（1.21 + 红标 + 08:00）
2. 《剧B》（1.21 + 无评级 + 10:00）

【1月22日 - 今天】
3. 《剧C》（1.22 + 红标 + 09:00）
4. 《剧D》（1.22 + 绿标 + 08:00）
5. 《剧E》（1.22 + 无评级 + 07:00）

【1月23日 - 未来】
6. 《剧F》（1.23 + 红标 + 11:00）
```

**关键点**：
1. 日期优先级永远是最高的（1.21 > 1.22 > 1.23）
2. 在同一天内，评级优先级生效（红标 > 绿标 > 黄标 > 无评级）
3. 在同一评级内，按上架时间排序

## 五、如何在飞书设置评级

### 步骤1：添加评级字段

确保你的飞书表格中有一个名为"评级"的字段（单选或文本字段均可）。

### 步骤2：设置评级值

在需要优先处理的短剧行中，将"评级"字段设置为：
- **红标**：最高优先级
- **绿标**：次高优先级  
- **黄标**：一般优先级
- 留空或其他值：最低优先级

### 步骤3：保存并等待系统处理

系统会在下一次查询时自动识别评级，并按优先级排序处理。

## 六、导出目录规则

系统剪辑完成后，生成的素材会自动保存到导出目录中。

### 6.1 默认导出目录

**Windows 系统默认路径**：`D:\短剧剪辑\导出素材`

如果你的源视频目录是：`D:\短剧剪辑\源素材视频`  
那么导出目录就是：`D:\短剧剪辑\导出素材`

### 6.2 导出目录结构

导出的素材会按照以下结构组织：

**标准结构（不带日期）**：
```
D:\短剧剪辑\导出素材\
├── 霸总的娇妻\
│   ├── 霸总的娇妻_1.mp4
│   ├── 霸总的娇妻_2.mp4
│   ├── 霸总的娇妻_3.mp4
│   └── ...
├── 重生后我逆袭\
│   ├── 重生后我逆袭_1.mp4
│   ├── 重生后我逆袭_2.mp4
│   └── ...
└── 千金大小姐\
    ├── 千金大小姐_1.mp4
    ├── 千金大小姐_2.mp4
    └── ...
```

**带日期的结构**（如果配置了日期）：
```
D:\短剧剪辑\导出素材\
└── 1.22导出\
    ├── 霸总的娇妻\
    │   ├── 霸总的娇妻_1.mp4
    │   ├── 霸总的娇妻_2.mp4
    │   └── ...
    ├── 重生后我逆袭\
    │   ├── 重生后我逆袭_1.mp4
    │   └── ...
    └── 千金大小姐\
        └── ...
```

### 6.3 文件命名规则

生成的素材文件命名格式：`{剧名}_{序号}.mp4`

**例子**：
- 第1条素材：`霸总的娇妻_1.mp4`
- 第2条素材：`霸总的娇妻_2.mp4`
- 第3条素材：`霸总的娇妻_3.mp4`

### 6.4 如何找到导出的素材

**方法1：按剧名查找**

如果你想找某部剧的素材，直接打开：
```
D:\短剧剪辑\导出素材\{剧名}\
```

**方法2：查看飞书状态**

剪辑完成后，飞书表格中的状态会更新为"已剪辑"，说明素材已导出完成。

**方法3：查看系统日志**

系统日志会显示每部剧的导出目录路径，例如：
```
✅ 霸总的娇妻 完成：5/5 条素材
   目录: D:\短剧剪辑\导出素材\霸总的娇妻
```

### 6.5 特殊说明

#### 自定义导出目录

如果管理员配置了不同的导出目录（例如 `E:\短剧剪辑\输出素材`），那么：
- 素材会保存到配置的目录
- 目录结构和文件命名规则保持一致

#### 断点续传

如果某部剧已经导出了部分素材，再次剪辑时：
- 系统会检查现有素材数量
- 只生成缺少的素材（不会重复生成）
- 新生成的素材编号会接着上次的编号继续

**例子**：
```
第1次剪辑：生成了 3 条素材（霸总的娇妻_1.mp4 ~ _3.mp4）
第2次剪辑：需要总共 5 条素材
结果：只生成 2 条新素材（霸总的娇妻_4.mp4 ~ _5.mp4）
```

## 七、常见问题

### Q1：我可以自定义评级的名称吗？

**可以，但需要修改配置文件。**

默认配置：
- 红标（最高优先级）
- 绿标（次高）
- 黄标（一般）

如果你想使用其他名称（如"⭐⭐⭐"、"紧急"等），需要在配置文件中修改对应字段。

### Q2：如果我不设置评级会怎样？

**不设置评级的短剧会在最后处理。**

例如：同一天有3部红标、2部绿标、5部无评级的短剧，系统会先处理3部红标，再处理2部绿标，最后处理5部无评级的。

### Q3：评级能覆盖日期优先级吗？

**不能。日期优先级永远是最高的。**

例如：
- 1月21日的无评级短剧
- 1月22日的红标短剧

系统会先处理1月21日的无评级短剧（因为日期更早），再处理1月22日的红标短剧。

### Q4：如果多部短剧都是红标，怎么决定先处理哪一部？

**按上架时间排序。**

同评级内：
1. 今天上架的短剧优先于昨天上架的
2. 同一天上架的，按上架时间升序排序（越早越优先）

### Q5：处理过程中我修改了评级，会立即生效吗？

**会的，但有延迟。**

系统每处理完一部短剧都会重新查询飞书并重新排序。所以：
- 如果正在处理的短剧还没处理完，修改不会影响当前短剧
- 处理完后，系统会立即查询到修改后的评级，并按新的优先级排序

## 八、最佳实践建议

### 1. 合理使用红标

- 红标应该用于真正紧急、重要的短剧
- 避免所有短剧都标记为红标，这样会失去优先级的意义

### 2. 评级与日期配合

- 对于已过期的日期，建议标记为红标，确保最优先处理
- 对于未来日期，可以根据实际情况灵活设置评级

### 3. 定期检查评级

- 已处理的短剧可以清除评级
- 根据实际情况动态调整评级

### 4. 查看处理日志

- 系统会在日志中显示完整的排序结果
- 可以通过日志确认你的评级设置是否正确生效

## 九、评级优先级 vs 普通优先级

### 普通用户（不启用评级）

排序规则：
```
日期优先级 → 上架时间优先级
```

### xh-daily 用户（启用评级）

排序规则：
```
日期优先级 → 评级优先级 → 上架时间优先级
```

**区别**：xh-daily 用户在同一天内多了一层"评级优先级"的控制。

## 十、总结

xh-daily 用户的评级优先级功能，让你能够更精细地控制同一天内短剧的处理顺序：

**📅 日期越早，优先级越高（永远是第一优先级）**  
**🏷️ 同一天内，评级越高，优先级越高（红标 > 绿标 > 黄标）**  
**⏰ 同一评级内，上架时间越早，优先级越高**  
**🔄 每处理完一部，立即重新查询和排序**

通过合理使用评级功能，你可以确保重要的短剧总是被优先处理，提升整体工作效率！
