## 🚀 一键安装

### 第一步：获取工具包

管理员会给你提供一个压缩包，解压到任意位置（建议：`D:\短剧工具\`）

### 第二步：运行安装脚本

1. 进入工具目录
2. **右键点击** `一键安装.ps1`
3. 选择 **"使用 PowerShell 运行"**

```powershell
# 脚本会自动安装：
# ✅ Python 3.12
# ✅ FFmpeg（视频处理工具）
# ✅ 所有依赖包
```

> ⚠️ **注意**：如果提示"无法运行脚本"，请先以管理员身份运行 PowerShell，执行：
>
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

### 第三步：配置你的账号

在 `configs/users/` 文件夹中，管理员已经为你创建了配置文件：

- `xh.yaml` - 小红账号（35 个素材/剧）
- `xh-daily.yaml` - 小红日常（20 个素材/剧）
- `xl.yaml` - 小李账号
- `xx.yaml` - 小雪账号

**无需修改**，管理员已配置好！

## 🎯 快速开始

### 方式一：命令行模式（推荐）

#### 1. 启动工具

双击运行 `启动命令行.bat`，或者：

```powershell
# 进入工具目录
cd D:\短剧工具\dramas_processor

# 激活虚拟环境
.\venv\Scripts\Activate.ps1

# 查看帮助
python -m drama_processor --help
```

#### 2. 处理单个剧集

```powershell
# 使用你的配置文件（如 xh）
python -m drama_processor process "D:\短剧剪辑\源素材视频" --config configs/users/xh.yaml

# 指定剧名
python -m drama_processor process "D:\短剧剪辑\源素材视频" --include "重回校园我成了魅力男神" --config configs/users/xh.yaml

# 指定日期
python -m drama_processor process "D:\短剧剪辑\源素材视频" --date "1.16" --config configs/users/xh.yaml
```

#### 3. 常用参数说明

| 参数        | 说明                     | 示例                             |
| ----------- | ------------------------ | -------------------------------- |
| `--config`  | 使用的配置文件           | `--config configs/users/xh.yaml` |
| `--include` | 指定剧名（支持模糊匹配） | `--include "重回校园"`           |
| `--exclude` | 排除剧名                 | `--exclude "测试剧"`             |
| `--date`    | 日期标识（用于文件命名） | `--date "1.16"`                  |
| `--count`   | 生成素材数量             | `--count 30`                     |
| `--full`    | 处理整部剧（不随机）     | `--full`                         |

## 📱 飞书自动化

### 什么是飞书自动化？

自动从飞书多维表格获取待剪辑的剧集列表，按优先级自动处理，无需手动输入剧名。

### 启动飞书监控

```powershell
# 使用你的配置文件
python -m drama_processor feishu watch --config configs/users/xh-daily.yaml
```

### 工作流程

1. **自动查询**：每剪完一部剧，立即查询飞书表格
2. **智能排序**：
   - 今天的剧 > 昨天的剧 > 未来的剧
   - 红标 > 绿标 > 黄标（仅 xh-daily 配置）
   - 新上架的 > 早上架的
3. **自动剪辑**：按优先级依次处理
4. **状态更新**：剪完后自动更新飞书状态为"待上传"

### 飞书表格字段说明

你的飞书表格需要包含以下字段：

| 字段名   | 说明                        | 必需 |
| -------- | --------------------------- | ---- |
| 剧名     | 剧集名称                    | ✅   |
| 日期     | 上架日期（如 1.16）         | ✅   |
| 当前状态 | 待剪辑/剪辑中/待上传/已完成 | ✅   |
| 上架时间 | 时间戳（用于排序）          | 推荐 |
| 评级     | 红标/绿标/黄标              | 可选 |

### 监控状态

```
🚀 启动飞书轮询：每 1800s 轮询一次，状态过滤=待剪辑
📚 分组结果：1.15:2部, 1.16:3部
🎯 日期 1.15 检测到待剪辑剧，开始处理
🎬 开始处理 1.15 - 重回校园我成了魅力男神
✅ 重回校园我成了魅力男神 完成：30/30 条素材
```

## 🎨 素材输出说明

### 输出目录结构

```
导出素材/
└── 1.16导出/                    # 按日期分组
    ├── xh-重回校园-01.mp4        # xh 是你的账号标识
    ├── xh-重回校园-02.mp4
    ├── ...
```

### 文件命名规则

- `xh`：账号标识（material_code）
- `重回校园`：剧名（自动提取）

| 06-10    | 小红看剧 |
| 11-15    | 哈哈看剧 |
| 16-20    | 看家本领 |
| 21-23    | 葸辉爆剧 |
| 24-25    | 清妍短剧 |
| 26-30    | 排桐剧场 |

每个素材会自动添加对应的品牌文案到视频左上角。

## ❓ 常见问题

### 1. 提示"找不到 Python"

**解决方法**：

```powershell
# 重新运行一键安装脚本
.\一键安装.ps1

# 或者手动安装 Python
winget install Python.Python.3.12

# 安装完成后重启 PowerShell
```

### 2. 提示"找不到 FFmpeg"

**解决方法**：

```powershell
# 检查 FFmpeg 是否安装
ffmpeg -version

# 如果没有，手动安装
winget install Gyan.FFmpeg
```

### 3. 提示"硬件编码器不可用"

**不影响使用**，会自动切换到软件编码（速度稍慢）

**如果需要硬件加速**：

- 确保你有 NVIDIA 显卡
- 更新显卡驱动到最新版本
- 参考：[硬件编码器故障排除](HARDWARE_ENCODER_TROUBLESHOOTING.md)

### 4. 剪辑速度慢怎么办？

**优化建议**：

1. **使用 SSD**：将源素材和输出目录都放在 SSD 上
2. **启用硬件加速**：使用 NVIDIA 显卡的 NVENC 编码器
3. **减少并发数**：如果内存不足，在配置文件中设置 `jobs: 1`
4. **启用快速模式**：在配置文件中设置 `fast_mode: true`

### 5. 如何修改生成素材数量？

编辑你的配置文件（如 `configs/users/xh.yaml`）：

```yaml
# 素材生成设置
count: 30 # 改成你想要的数量
```

### 6. 飞书自动化没有反应？

**检查清单**：

1. ✅ 飞书配置是否正确（app_id、app_secret 等）
2. ✅ 网络是否正常（能否访问飞书 API）
3. ✅ 表格中是否有"待剪辑"状态的剧集
4. ✅ 源素材目录中是否有对应的剧集文件夹

**查看详细日志**：

```powershell
python -m drama_processor feishu watch --config configs/users/xh-daily.yaml --verbose
```

### 7. 如何停止飞书监控？

按 `Ctrl + C` 即可安全停止。当前正在处理的剧集会完成后退出。

### 8. 素材质量不好怎么办？

**调整参数**：

- `min_duration: 480`：最小时长（秒），默认 8 分钟
- `max_duration: 900`：最大时长（秒），默认 15 分钟
- `exclude_last_episodes: 8`：排除最后 N 集（避免结局剧透）

### 9. 如何批量处理多部剧？

**方法一：使用通配符**

```powershell
# 处理所有包含"重回"的剧
python -m drama_processor process "D:\短剧剪辑\源素材视频" --include "*重回*" --config configs/users/xh.yaml
```

**方法二：使用飞书自动化**
在飞书表格中添加多部剧，启动 watch 模式即可自动批量处理。

### 10. 如何更新工具？

```powershell
# 进入工具目录
cd D:\短剧工具\dramas_processor

# 拉取最新代码
git pull

# 更新依赖（如果有新依赖）
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 🎓 进阶技巧

### 自动化脚本

创建 `auto_watch.bat` 文件，双击即可启动监控：

```batch
@echo off
cd /d D:\短剧工具\dramas_processor
call venv\Scripts\activate.bat
python -m drama_processor feishu watch --config configs/users/xh-daily.yaml
pause
```

### 定时任务

使用 Windows 任务计划程序，设置每天自动启动监控。

### 多账号并行

如果你有多个账号，可以同时运行多个 PowerShell 窗口，分别使用不同的配置文件。
