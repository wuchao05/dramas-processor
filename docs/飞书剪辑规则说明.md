# 飞书剪辑规则说明

> 本文档面向非技术人员，详细说明飞书自动监控剪辑的工作规则和优先级逻辑。

## 一、什么是飞书自动监控剪辑

飞书自动监控剪辑是一个"自动化管家"，它会：
- 📡 **持续监控**飞书表格中标记为"待剪辑"的短剧
- 🎯 **自动选择**优先级最高的短剧进行剪辑
- 🔄 **处理完后立即**查询下一部需要剪辑的短剧
- ⏰ **没有待剪辑短剧时**每20分钟查询一次，等待新任务

简单来说：你只需要在飞书表格里标记好"待剪辑"的短剧，系统会自动按照规则处理，完全不需要手动操作。

---

## 二、剪辑优先级规则

系统会按照以下规则自动排列所有待剪辑短剧的优先级：

### 规则1：日期优先级（最重要）

**越早的日期，优先级越高。**

假设今天是 **1月22日**，飞书表格中有：
- 1月21日的短剧（昨天）
- 1月22日的短剧（今天）
- 1月23日的短剧（明天）

**处理顺序**：
```
第1优先：1月21日（已过期的日期，最优先）
第2优先：1月22日（今天的日期）
第3优先：1月23日（未来的日期，最后处理）
```

**更多例子**：
- 如果有1月19日、1月20日、1月21日、1月22日的短剧：
  - 先处理完1月19日的所有短剧
  - 再处理1月20日的所有短剧
  - 再处理1月21日的所有短剧
  - 最后处理1月22日的所有短剧

**核心原则**：**已过期的日期 > 今天 > 未来的日期**

### 规则2：同一天内的上架时间优先级

如果多部短剧都是同一个日期，系统会看"上架时间"：

**越早上架的，优先级越高。**

**例子**：1月22日有5部待剪辑的短剧
- 短剧A：上架时间 1月22日 08:00
- 短剧B：上架时间 1月22日 09:30
- 短剧C：上架时间 1月22日 12:00
- 短剧D：上架时间 1月21日 15:00
- 短剧E：上架时间 1月21日 18:00

**处理顺序**：
```
1. 短剧D（1月21日 15:00，上架时间最早）
2. 短剧E（1月21日 18:00）
3. 短剧A（1月22日 08:00）
4. 短剧B（1月22日 09:30）
5. 短剧C（1月22日 12:00）
```

**核心原则**：今天上架的短剧优先于昨天上架的，同一天上架的按时间先后排序。

### 规则3：特殊用户的评级优先级

对于 `xh-daily` 用户（启用了评级优先级功能），在同一天内会先按评级排序：

**红标 > 绿标 > 黄标 > 其他**

然后再按上架时间排序。

**例子**：1月22日有3部待剪辑的短剧
- 短剧A：绿标，上架时间 08:00
- 短剧B：红标，上架时间 10:00
- 短剧C：黄标，上架时间 09:00

**处理顺序（启用评级优先级时）**：
```
1. 短剧B（红标，即使上架时间晚，但评级最高）
2. 短剧A（绿标）
3. 短剧C（黄标）
```

## 三、完整的优先级排序逻辑

系统会按照这个顺序来决定先剪辑哪部短剧：

```
第1步：按日期分组
   └─ 已过期的日期（越早越优先）
   └─ 今天的日期
   └─ 未来的日期（越近越优先）

第2步：在同一日期内
   └─ 【仅 xh-daily 用户】先按评级排序（红标 > 绿标 > 黄标）
   └─ 今天上架的短剧优先
   └─ 在各自组内按上架时间升序排序（越早越优先）
```

## 四、实际场景示例

### 场景1：跨日期优先级

**今天是：1月22日**

**飞书表格中的待剪辑短剧**：
- 1月20日：《霸总的娇妻》《重生后我逆袭》
- 1月21日：《千金大小姐》
- 1月22日：《甜蜜暴击》《恋爱脑》《豪门千金》
- 1月23日：《星辰大海》

**实际处理顺序**：
```
1. 《霸总的娇妻》（1月20日，最早过期）
2. 《重生后我逆袭》（1月20日）
3. 《千金大小姐》（1月21日）
4. 《甜蜜暴击》（1月22日，今天）
5. 《恋爱脑》（1月22日，今天）
6. 《豪门千金》（1月22日，今天）
7. 《星辰大海》（1月23日，明天，最后处理）
```

### 场景2：同一天内按上架时间排序

**今天是：1月22日**

**1月22日的待剪辑短剧**（按上架时间）：
- 《甜蜜暴击》：1月22日 08:00 上架
- 《恋爱脑》：1月22日 10:30 上架
- 《豪门千金》：1月21日 18:00 上架
- 《星光闪耀》：1月21日 20:00 上架

**实际处理顺序**：
```
1. 《豪门千金》（1月21日 18:00，今天上架中最早的）
2. 《星光闪耀》（1月21日 20:00）
3. 《甜蜜暴击》（1月22日 08:00）
4. 《恋爱脑》（1月22日 10:30）
```

### 场景3：动态响应优先级变化

**初始状态**（今天是1月22日）：
- 1月22日：5部待剪辑短剧

**处理流程**：
```
10:00 - 系统查询飞书，发现1月22日有5部短剧
10:00 - 开始处理第1部短剧
11:30 - 第1部处理完成，立即查询飞书
11:30 - 发现1月21日新增了2部短剧！
11:30 - 系统重新排序，优先处理1月21日的短剧（因为日期更早）
11:30 - 开始处理1月21日的第1部短剧
```

**关键点**：每处理完一部短剧，系统都会重新查询飞书并重新排序，确保始终优先处理日期最早的短剧。

## 五、轮询机制说明

### 有待剪辑短剧时

系统会：
1. 查询飞书表格
2. 按优先级排序所有待剪辑短剧
3. 选择优先级最高的一部短剧进行剪辑
4. 剪辑完成后，**立即**回到第1步（不等待）

**这意味着**：只要有待剪辑的短剧，系统就会持续工作，不会停下来。

### 没有待剪辑短剧时

当所有短剧都处理完后：
1. 系统会提示"✅ 所有待剪辑的剧已处理完成，进入外层轮询"
2. 等待 **20分钟**
3. 再次查询飞书表格，看是否有新的待剪辑短剧
4. 如果有，立即开始处理
5. 如果没有，继续等待20分钟

**这意味着**：系统会一直运行，自动等待新任务，不需要手动启动。

## 六、常见问题

### Q1：为什么我的短剧没有被立即处理？

**可能原因**：
- 你的短剧日期比其他短剧晚（例如：其他短剧是1月21日，你的是1月22日）
- 你的短剧上架时间比其他同日期短剧晚

**解决方法**：
- 系统会按优先级顺序处理，请耐心等待前面的短剧处理完成
- 可以在飞书查看当前有多少待剪辑短剧，预估处理时间

### Q2：我在飞书新增了一部更早日期的短剧，系统会调整优先级吗？

**会的！**

系统每处理完一部短剧都会重新查询和排序。

**例子**：
- 正在处理1月22日的短剧
- 你在飞书新增了1月20日的短剧
- 当前短剧处理完后，系统会立即发现1月20日的短剧（优先级更高）
- 系统会优先处理1月20日的短剧

### Q3：如何知道系统正在处理哪部短剧？

系统会在日志中显示：
- 📊 查询到的所有待剪辑短剧列表
- 🎯 当前选择处理的短剧
- ✅ 处理完成的短剧

同时，飞书表格中的状态会自动更新：
- 开始处理时：状态变为"剪辑中"
- 处理完成后：状态变为"已剪辑"或"剪辑失败"

### Q4：系统会同时处理多部短剧吗？

**不会。**

系统每次只处理一部短剧，处理完后立即查询下一部。这样做的好处是：
- 确保优先级实时更新
- 避免资源冲突
- 便于追踪进度

### Q5：如果系统正在处理短剧，我在飞书修改了日期，会有影响吗？

**不会影响正在处理的短剧。**

但是：
- 处理完当前短剧后，系统会重新查询飞书
- 修改后的日期会在下一次查询时生效
- 系统会按新的日期重新排序剩余的短剧

## 七、最佳实践建议

### 1. 合理设置日期

- 建议按照短剧的实际上线日期设置
- 已过期的短剧会被优先处理
- 避免所有短剧都设置成同一天，这样无法利用日期优先级

### 2. 标记清晰

- 确保待剪辑的短剧状态设置为"待剪辑"
- 已处理的短剧系统会自动更新状态，不需要手动修改

### 3. 查看日志

- 系统会详细记录每次查询和处理的情况
- 如果有疑问，可以查看日志了解系统的决策过程

### 4. 合理安排上架时间

- 如果同一天有多部短剧，可以通过调整上架时间来控制处理顺序
- 更重要的短剧可以设置更早的上架时间

## 八、总结

飞书自动监控剪辑的核心规则很简单：

**📅 日期越早，优先级越高**  
**⏰ 同一天内，上架时间越早，优先级越高**  
**🔄 每处理完一部，立即重新查询和排序**  
**⏱️ 没有任务时，每20分钟查询一次**

只要记住这四点，就能完全理解系统的工作逻辑。系统会7×24小时自动运行，你只需要在飞书表格里标记好待剪辑的短剧，剩下的交给系统处理即可！
