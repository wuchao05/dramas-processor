# 飞书剪辑规则说明

> 本文档面向非技术人员，详细说明飞书自动监控剪辑的工作规则和优先级逻辑。

## 一、什么是飞书自动监控剪辑

飞书自动监控剪辑是一个"自动化管家"，它会：
- 📡 **持续监控**飞书表格中标记为"待剪辑"的短剧
- 🎯 **自动选择**优先级最高的短剧进行剪辑
- 🔄 **处理完后立即**查询下一部需要剪辑的短剧
- ⏰ **没有待剪辑短剧时**每20分钟查询一次，等待新任务

简单来说：你只需要在飞书表格里标记好"待剪辑"的短剧，系统会自动按照规则处理，完全不需要手动操作。

## 二、前提条件：源视频目录要求

### 重要提示

**系统只会处理本地存在源视频的短剧！**

在飞书表格中标记"待剪辑"之前，请确保：

### 2.1 源视频目录结构

系统会在配置的源视频目录（默认：`D:\短剧剪辑\源素材视频`）中查找短剧。

**目录结构要求**：
```
D:\短剧剪辑\源素材视频\
├── 霸总的娇妻\
│   ├── 第1集.mp4
│   ├── 第2集.mp4
│   └── ...
├── 重生后我逆袭\
│   ├── 第1集.mp4
│   ├── 第2集.mp4
│   └── ...
└── 千金大小姐\
    ├── 第1集.mp4
    ├── 第2集.mp4
    └── ...
```

### 2.2 剧名必须完全匹配

**关键规则**：飞书表格中的剧名必须与文件夹名称**完全一致**（包括大小写、空格、标点符号）。

**正确示例**：
- 飞书剧名：`霸总的娇妻` → 文件夹：`霸总的娇妻` ✅
- 飞书剧名：`重生后我逆袭` → 文件夹：`重生后我逆袭` ✅

**错误示例**：
- 飞书剧名：`霸总的娇妻` → 文件夹：`霸总的娇妻(完结)` ❌
- 飞书剧名：`重生后我逆袭` → 文件夹：`重生后我逆袭 ` ❌（多了空格）
- 飞书剧名：`千金大小姐` → 文件夹：`千金小姐` ❌（剧名不同）

### 2.3 源视频文件要求

- 支持的视频格式：`.mp4`、`.mkv`、`.avi`、`.mov` 等常见格式
- 文件命名可以是：`第1集.mp4`、`1.mp4`、`ep01.mp4` 等
- 至少需要有足够的集数来生成所需数量的素材

### 2.4 系统处理逻辑

当系统选择处理某部短剧时：

**情况1：找不到文件夹**
```
系统查找：D:\短剧剪辑\源素材视频\霸总的娇妻
结果：文件夹不存在
操作：飞书状态更新为"无源视频"，跳过该剧
```

**情况2：文件夹存在但视频不足**
```
系统查找：D:\短剧剪辑\源素材视频\霸总的娇妻
结果：文件夹存在，但只有3集视频（需要至少8集）
操作：飞书状态更新为"剪辑失败"，备注"请检查源素材目录中是否存在足额的源视频"
```

**情况3：正常处理**
```
系统查找：D:\短剧剪辑\源素材视频\霸总的娇妻
结果：文件夹存在，有充足的视频文件
操作：开始剪辑，飞书状态更新为"剪辑中" → "已剪辑"
```

## 三、剪辑优先级规则

系统会按照以下规则自动排列所有待剪辑短剧的优先级：

### 规则1：日期优先级（最重要）

**越早的日期，优先级越高。**

假设今天是 **1月22日**，飞书表格中有：
- 1月21日的短剧（昨天）
- 1月22日的短剧（今天）
- 1月23日的短剧（明天）

**处理顺序**：
```
第1优先：1月21日（已过期的日期，最优先）
第2优先：1月22日（今天的日期）
第3优先：1月23日（未来的日期，最后处理）
```

**更多例子**：
- 如果有1月19日、1月20日、1月21日、1月22日的短剧：
  - 先处理完1月19日的所有短剧
  - 再处理1月20日的所有短剧
  - 再处理1月21日的所有短剧
  - 最后处理1月22日的所有短剧

**核心原则**：**已过期的日期 > 今天 > 未来的日期**

### 规则2：同一天内的上架时间优先级

如果多部短剧都是同一个日期，系统会看"上架时间"：

**越早上架的，优先级越高。**

**例子**：1月22日有5部待剪辑的短剧
- 短剧A：上架时间 1月22日 08:00
- 短剧B：上架时间 1月22日 09:30
- 短剧C：上架时间 1月22日 12:00
- 短剧D：上架时间 1月21日 15:00
- 短剧E：上架时间 1月21日 18:00

**处理顺序**：
```
1. 短剧D（1月21日 15:00，上架时间最早）
2. 短剧E（1月21日 18:00）
3. 短剧A（1月22日 08:00）
4. 短剧B（1月22日 09:30）
5. 短剧C（1月22日 12:00）
```

**核心原则**：今天上架的短剧优先于昨天上架的，同一天上架的按时间先后排序。

---

## 四、完整的优先级排序逻辑

系统会按照这个顺序来决定先剪辑哪部短剧：

```
第1步：按日期分组
   └─ 已过期的日期（越早越优先）
   └─ 今天的日期
   └─ 未来的日期（越近越优先）

第2步：在同一日期内
   └─ 今天上架的短剧优先
   └─ 在各自组内按上架时间升序排序（越早越优先）
```

## 五、实际场景示例

### 场景1：跨日期优先级

**今天是：1月22日**

**飞书表格中的待剪辑短剧**：
- 1月20日：《霸总的娇妻》《重生后我逆袭》
- 1月21日：《千金大小姐》
- 1月22日：《甜蜜暴击》《恋爱脑》《豪门千金》
- 1月23日：《星辰大海》

**实际处理顺序**：
```
1. 《霸总的娇妻》（1月20日，最早过期）
2. 《重生后我逆袭》（1月20日）
3. 《千金大小姐》（1月21日）
4. 《甜蜜暴击》（1月22日，今天）
5. 《恋爱脑》（1月22日，今天）
6. 《豪门千金》（1月22日，今天）
7. 《星辰大海》（1月23日，明天，最后处理）
```

### 场景2：同一天内按上架时间排序

**今天是：1月22日**

**1月22日的待剪辑短剧**（按上架时间）：
- 《甜蜜暴击》：1月22日 08:00 上架（今天上架）
- 《恋爱脑》：1月22日 10:30 上架（今天上架）
- 《豪门千金》：1月21日 18:00 上架（昨天上架）
- 《星光闪耀》：1月21日 20:00 上架（昨天上架）

**实际处理顺序**：
```
1. 《甜蜜暴击》（今天上架 08:00，今天上架中最早的）
2. 《恋爱脑》（今天上架 10:30）
3. 《豪门千金》（昨天上架 18:00，昨天上架中最早的）
4. 《星光闪耀》（昨天上架 20:00）
```

**说明**：今天上架的短剧优先于昨天上架的，在各自组内按上架时间从早到晚排序。

### 场景3：动态响应优先级变化

**初始状态**（今天是1月22日）：
- 1月22日：5部待剪辑短剧

**处理流程**：
```
10:00 - 系统查询飞书，发现1月22日有5部短剧
10:00 - 开始处理第1部短剧
11:30 - 第1部处理完成，立即查询飞书
11:30 - 发现1月21日新增了2部短剧！
11:30 - 系统重新排序，优先处理1月21日的短剧（因为日期更早）
11:30 - 开始处理1月21日的第1部短剧
```

**关键点**：每处理完一部短剧，系统都会重新查询飞书并重新排序，确保始终优先处理日期最早的短剧。

## 六、导出目录规则

系统剪辑完成后，生成的素材会自动保存到导出目录中。

### 6.1 默认导出目录

**Windows 系统默认路径**：`D:\短剧剪辑\导出素材`

如果你的源视频目录是：`D:\短剧剪辑\源素材视频`  
那么导出目录就是：`D:\短剧剪辑\导出素材`

### 6.2 导出目录结构

导出的素材会按照以下结构组织：

**标准结构（不带日期）**：
```
D:\短剧剪辑\导出素材\
├── 霸总的娇妻\
│   ├── 霸总的娇妻_1.mp4
│   ├── 霸总的娇妻_2.mp4
│   ├── 霸总的娇妻_3.mp4
│   └── ...
├── 重生后我逆袭\
│   ├── 重生后我逆袭_1.mp4
│   ├── 重生后我逆袭_2.mp4
│   └── ...
└── 千金大小姐\
    ├── 千金大小姐_1.mp4
    ├── 千金大小姐_2.mp4
    └── ...
```

**带日期的结构**（如果配置了日期）：
```
D:\短剧剪辑\导出素材\
└── 1.22导出\
    ├── 霸总的娇妻\
    │   ├── 霸总的娇妻_1.mp4
    │   ├── 霸总的娇妻_2.mp4
    │   └── ...
    ├── 重生后我逆袭\
    │   ├── 重生后我逆袭_1.mp4
    │   └── ...
    └── 千金大小姐\
        └── ...
```

### 6.3 文件命名规则

生成的素材文件命名格式：`{剧名}_{序号}.mp4`

**例子**：
- 第1条素材：`霸总的娇妻_1.mp4`
- 第2条素材：`霸总的娇妻_2.mp4`
- 第3条素材：`霸总的娇妻_3.mp4`

### 6.4 如何找到导出的素材

**方法1：按剧名查找**

如果你想找某部剧的素材，直接打开：
```
D:\短剧剪辑\导出素材\{剧名}\
```

**方法2：查看飞书状态**

剪辑完成后，飞书表格中的状态会更新为"已剪辑"，说明素材已导出完成。

**方法3：查看系统日志**

系统日志会显示每部剧的导出目录路径，例如：
```
✅ 霸总的娇妻 完成：5/5 条素材
   目录: D:\短剧剪辑\导出素材\霸总的娇妻
```

### 6.5 特殊说明

#### 自定义导出目录

如果管理员配置了不同的导出目录（例如 `E:\短剧剪辑\输出素材`），那么：
- 素材会保存到配置的目录
- 目录结构和文件命名规则保持一致

#### 断点续传

如果某部剧已经导出了部分素材，再次剪辑时：
- 系统会检查现有素材数量
- 只生成缺少的素材（不会重复生成）
- 新生成的素材编号会接着上次的编号继续

**例子**：
```
第1次剪辑：生成了 3 条素材（霸总的娇妻_1.mp4 ~ _3.mp4）
第2次剪辑：需要总共 5 条素材
结果：只生成 2 条新素材（霸总的娇妻_4.mp4 ~ _5.mp4）
```

## 七、轮询机制说明

### 有待剪辑短剧时

系统会：
1. 查询飞书表格
2. 按优先级排序所有待剪辑短剧
3. 选择优先级最高的一部短剧进行剪辑
4. 剪辑完成后，**立即**回到第1步（不等待）

**这意味着**：只要有待剪辑的短剧，系统就会持续工作，不会停下来。

### 没有待剪辑短剧时

当所有短剧都处理完后：
1. 系统会提示"✅ 所有待剪辑的剧已处理完成，进入外层轮询"
2. 等待 **20分钟**
3. 再次查询飞书表格，看是否有新的待剪辑短剧
4. 如果有，立即开始处理
5. 如果没有，继续等待20分钟

**这意味着**：系统会一直运行，自动等待新任务，不需要手动启动。

## 八、常见问题

### Q1：为什么我的短剧没有被立即处理？

**可能原因**：
- 你的短剧日期比其他短剧晚（例如：其他短剧是1月21日，你的是1月22日）
- 你的短剧上架时间比其他同日期短剧晚

**解决方法**：
- 系统会按优先级顺序处理，请耐心等待前面的短剧处理完成
- 可以在飞书查看当前有多少待剪辑短剧，预估处理时间

### Q2：我在飞书新增了一部更早日期的短剧，系统会调整优先级吗？

**会的！**

系统每处理完一部短剧都会重新查询和排序。

**例子**：
- 正在处理1月22日的短剧
- 你在飞书新增了1月20日的短剧
- 当前短剧处理完后，系统会立即发现1月20日的短剧（优先级更高）
- 系统会优先处理1月20日的短剧

### Q3：如何知道系统正在处理哪部短剧？

系统会在日志中显示：
- 📊 查询到的所有待剪辑短剧列表
- 🎯 当前选择处理的短剧
- ✅ 处理完成的短剧

同时，飞书表格中的状态会自动更新：
- 开始处理时：状态变为"剪辑中"
- 处理完成后：状态变为"已剪辑"或"剪辑失败"

### Q4：系统会同时处理多部短剧吗？

**不会。**

系统每次只处理一部短剧，处理完后立即查询下一部。这样做的好处是：
- 确保优先级实时更新
- 避免资源冲突
- 便于追踪进度

### Q5：如果系统正在处理短剧，我在飞书修改了日期，会有影响吗？

**不会影响正在处理的短剧。**

但是：
- 处理完当前短剧后，系统会重新查询飞书
- 修改后的日期会在下一次查询时生效
- 系统会按新的日期重新排序剩余的短剧

## 九、最佳实践建议

### 1. 合理设置日期

- 建议按照短剧的实际上线日期设置
- 已过期的短剧会被优先处理
- 避免所有短剧都设置成同一天，这样无法利用日期优先级

### 2. 标记清晰

- 确保待剪辑的短剧状态设置为"待剪辑"
- 已处理的短剧系统会自动更新状态，不需要手动修改

### 3. 查看日志

- 系统会详细记录每次查询和处理的情况
- 如果有疑问，可以查看日志了解系统的决策过程

### 4. 合理安排上架时间

- 如果同一天有多部短剧，可以通过调整上架时间来控制处理顺序
- 更重要的短剧可以设置更早的上架时间

## 十、总结

飞书自动监控剪辑的核心规则很简单：

**📅 日期越早，优先级越高**  
**⏰ 同一天内，今天上架的优先，按上架时间从早到晚排序**  
**🔄 每处理完一部，立即重新查询和排序**  
**⏱️ 没有任务时，每20分钟查询一次**

只要记住这四点，就能完全理解系统的工作逻辑。系统会7×24小时自动运行，你只需要在飞书表格里标记好待剪辑的短剧，剩下的交给系统处理即可！
