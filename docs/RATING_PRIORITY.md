# 飞书评级优先级功能

## 功能说明

在飞书 watch 模式下，支持根据"评级"字段对同日期内的剧目进行优先级排序，确保高优先级剧目最先被处理。

## 使用场景

当同一天有多部待剪辑的剧时，可以通过在飞书表格中设置"评级"字段，让标记为"红标"的剧目优先处理。

## 排序规则

在 `feishu watch` 模式下，剧目的处理顺序遵循以下规则：

### 1️⃣ 日期层面（外层优先级）
- ✅ **最高优先级**：今天或已过期的日期
- 📅 **次优先级**：未来日期
- 🔢 **同组内**：按距离今天的天数排序（越近越优先）

### 2️⃣ 同日期内的剧目（内层排序）⭐ **新增功能**
1. **评级为"红标"的剧** → 最优先处理
2. **非红标剧** → 按上架时间降序排序（越新越优先）
3. **没有上架时间的剧** → 排在最后

## 配置说明

在配置文件中添加了两个新字段：

```yaml
feishu:
  # ... 其他配置 ...
  rating_field_name: "评级"      # 评级字段名（可自定义）
  priority_rating_value: "红标"  # 高优先级评级值（可自定义）
```

### 配置项说明

- **rating_field_name**: 飞书表格中评级字段的名称（默认为"评级"）
- **priority_rating_value**: 表示高优先级的评级值（默认为"红标"）

如果你的飞书表格使用不同的字段名或评级标记，可以在用户配置中修改这两个值。

## 示例场景

假设今天是 1月13日，飞书表格中有以下待剪辑剧：

| 剧名 | 日期 | 评级 | 上架时间 |
|------|------|------|----------|
| 剧A | 1.13 | 红标 | 10:00 |
| 剧B | 1.13 | - | 15:00 |
| 剧C | 1.13 | 红标 | 08:00 |
| 剧D | 1.13 | - | 12:00 |
| 剧E | 1.14 | 红标 | 09:00 |
| 剧F | 1.14 | - | 16:00 |

**实际处理顺序**：
1. **剧A** (1.13 + 红标 + 10:00) → 今天+红标，上架时间较新
2. **剧C** (1.13 + 红标 + 08:00) → 今天+红标，上架时间较早
3. **剧B** (1.13 + 15:00) → 今天+非红标，上架时间新
4. **剧D** (1.13 + 12:00) → 今天+非红标，上架时间较早
5. **剧E** (1.14 + 红标 + 09:00) → 明天+红标
6. **剧F** (1.14 + 16:00) → 明天+非红标

## 配置文件位置

- 全局默认配置: `configs/default.yaml`
- 用户配置: `configs/users/xh-daily.yaml` (或其他用户配置)

## 技术实现

1. **feishu_client.py**: 在获取待剪辑剧信息时，额外获取"评级"字段
2. **feishu_watcher.py**: 在按日期分组后，对同日期内的剧按评级和上架时间排序
3. **models/feishu.py**: 添加配置项 `rating_field_name` 和 `priority_rating_value`

## 注意事项

- 该功能仅在 `feishu watch` 模式下生效
- 如果飞书表格中没有"评级"字段或该字段为空，不影响正常处理流程
- 可以通过修改配置自定义评级字段名和优先级标记值
