### 五、常见交付问题

#### Q1: 达人反馈"找不到 Python"

**原因**：一键安装脚本没有成功运行

**解决**：
1. 确认达人是否以管理员身份运行了 PowerShell
2. 确认网络连接正常
3. 手动安装：
   ```powershell
   winget install Python.Python.3.12
   winget install Gyan.FFmpeg
   ```

#### Q2: 达人反馈"无法运行脚本"

**原因**：PowerShell 执行策略限制

**解决**：
```powershell
# 以管理员身份运行 PowerShell，执行：
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

#### Q3: 达人反馈飞书监控没反应

**原因**：配置或网络问题

**检查**：
1. 飞书凭证是否正确
2. 网络是否能访问飞书 API
3. 飞书表格中是否有"待剪辑"状态的剧
4. 源素材目录是否有对应的剧集文件夹

#### Q4: 达人反馈找不到源素材

**原因**：源素材目录配置错误或文件夹名称不匹配

**解决**：
1. 检查配置文件中的 `default_source_dir` 路径
2. 确认剧名与文件夹名称完全一致
3. 建议使用绝对路径

#### Q5: 达人反馈素材质量不好

**原因**：参数设置不合适

**调整**：
```yaml
# 在配置文件中调整：
min_duration: 480     # 最小时长（秒）
max_duration: 900     # 最大时长（秒）
exclude_last_episodes: 8  # 排除最后N集
```
