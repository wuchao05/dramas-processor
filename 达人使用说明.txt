🚀 快速开始（3步）
───────────────────────────────────────────────────────────
第一步：安装环境
  方式A（推荐）：
    双击运行"运行一键安装.bat"
    等待安装完成（约 5-10 分钟）
  
  方式B（备用）：
    1. 右键点击"一键安装.ps1"
    2. 选择"使用 PowerShell 运行"
    3. 等待安装完成

第二步：准备素材
  确保你的源素材放在：D:\短剧剪辑\源素材视频\
  （每部剧一个文件夹，文件夹名即剧名）

第三步：开始剪辑
  方式A：飞书自动化（推荐）
    双击运行：启动飞书监控-xh.bat
    
  方式B：手动命令
    双击运行：启动命令行.bat
    输入命令：
      python -m drama_processor process "D:\短剧剪辑\源素材视频" --config configs/users/xh.yaml


📱 飞书自动化
───────────────────────────────────────────────────────────
功能：
  ✓ 自动读取飞书表格中的待剪辑剧集
  ✓ 按优先级智能排序（今天>昨天>未来，红标>绿标>黄标）
  ✓ 自动剪辑并更新状态
  ✓ 无需手动输入剧名

使用方法：
  1. 确保飞书表格已配置好（包含：剧名、日期、当前状态）
  2. 双击运行：启动飞书监控-xh.bat
  3. 工具会自动监控并处理

停止方法：
  按 Ctrl+C 可安全停止

❓ 常见问题
───────────────────────────────────────────────────────────
Q1: 提示"找不到 Python"？
A1: 重新运行"一键安装.ps1"，或手动安装 Python 3.12

Q2: 提示"找不到 FFmpeg"？
A2: 打开 PowerShell，运行：winget install Gyan.FFmpeg

Q3: 剪辑速度慢？
A3: 建议使用 SSD，或启用 NVIDIA 显卡硬件加速

Q4: 如何修改生成素材数量？
A4: 编辑配置文件 configs/users/xh.yaml，修改 count 值

Q5: 飞书监控没有反应？
A5: 检查飞书表格是否有"待剪辑"状态的剧集，查看源素材目录是否有对应文件夹

Q6: 如何停止监控？
A6: 按 Ctrl+C 安全停止

Q7: 如何更新工具？
A7: 联系管理员获取最新版本

✅ 使用检查清单
───────────────────────────────────────────────────────────
在开始剪辑前，请确认：
  □ Python 已安装（python --version 有输出）
  □ FFmpeg 已安装（ffmpeg -version 有输出）
  □ 配置文件准备好（如 xh.yaml）
  □ 源素材目录存在（D:\短剧剪辑\源素材视频\）
  □ 输出目录有足够空间（每部剧约 5-10GB）
  □ 飞书表格已配置（如使用飞书自动化）
